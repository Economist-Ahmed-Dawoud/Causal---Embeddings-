THE METHODOLOGY
===============================================================================

PROBLEM: Omitted Variable Bias
  - "Ability/savviness" confounds treatment and outcome
  - Unobserved in structured data → severe bias

INNOVATION: Text as Confounder Proxy
  - High ability → professional vocabulary, perfect grammar
  - Low ability → casual language, generic phrasing
  - LLM embeddings capture these patterns

SOLUTION: Double Machine Learning
  - Extract 384-dim embeddings from text
  - Use Lasso/RF to handle high dimensions
  - Cross-fitting prevents overfitting
  - Neyman orthogonality ensures consistency

TECHNICAL HIGHLIGHTS
===============================================================================

Data Generating Process:
  U ~ N(0,1)                          # Latent ability
  P(D=1) = sigmoid(1.5*U + 0.5*exp)  # Strong selection bias
  Y = 10 + 5.0*D + 8.0*U + ...       # TRUE EFFECT = 5.0

DML Estimator:
  τ̂ = Σ(D - D̂)(Y - Ŷ) / Σ(D - D̂)²
  where D̂, Ŷ include 384-dim text embeddings

Neyman Orthogonality:
  Ensures estimation errors in nuisance models don't bias causal estimate
